# 客户端

包名：`torse-client`。当前提供离屏渲染：装配世界、生成周边分区、按修订戳生成网格、上传显卡，并把一帧渲染成 PNG。窗口、输入与连续循环尚未接入，管线与缓冲就是后续窗口路径要复用的部分。

## 运行

```sh
cargo run -p torse-client -- --capture out.png --width 960 --height 720 --radius 2
```

| 参数 | 含义 |
|---|---|
| `--capture` | 输出 PNG 路径，必填 |
| `--width`、`--height` | 图像尺寸，默认 960x540 |
| `--radius` | 分区半径，默认 2，即(2r+1)平方个分区 |
| `--view` | `overview` 或 `player`，默认俯视全景 |

需要可用的图形后端。本机实测走 Vulkan，集显即可。CI 不执行渲染，只做编译检查。

## 组成

| 文件 | 职责 |
|---|---|
| [scene.rs](src/scene.rs) | 装配`WorldAuthority`、注入丘陵生成器、按半径装载并建网格、汇总顶点 |
| [renderer.rs](src/renderer.rs) | wgpu 设备与管线、深度与颜色目标、绘制与回读 PNG |
| [camera.rs](src/camera.rs) | 透视与视图矩阵，列主序，深度0到1 |
| [main.rs](src/main.rs) | 参数解析、一帧渲染与计数输出 |

顶点为位置、法线、颜色各三浮点，共36字节，按材质映射到一个扁平颜色，光照由法线与固定方向光决定。场景只使用内容夹具里的石头，颜色映射对玻璃半砖与植物同样生效。

## 边界

- 只渲染一帧，无动画与输入；着色器无纹理与阴影。
- 分区固定 `y = 0` 层，半径外直接卸载。
- 未接入 `Simulation`，画面里没有实体；实体渲染随窗口循环一起补。
- 代码不写世界，仅通过只读查询与网格任务读取。
