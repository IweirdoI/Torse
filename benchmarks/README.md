# 验证与测量记录

本目录保存各次验证的复现命令、运行环境、画面、测量结果与未覆盖范围。记录中的日期和代码状态决定其适用范围；早期记录里尚未实现的能力，可能已由后续记录补齐。当前使用方式见[项目README](../README.md)和各应用说明。

现有资料主要验证正确性与故障处理。[帧预算记录](M6-frame-budget.md)包含指定设备上的Release对照测量，尚未建立覆盖不同设备、规模和负载的统一性能基准。

## 记录要求

新增记录应写明代码与依赖版本、系统、硬件、内容配置和工作负载，给出可复跑命令，并保留原始指标。区分功能正确性、进程退出、硬件断电与性能测量，未验证的范围应明确说明。临时世界、日志和截图放入`.work/`，最终画面与必要夹具随对应记录保存。
