# 基础游戏

本目录保存基础游戏的界面素材、物品图标与本地化文案，资源结构见[assets](assets/README.md)。客户端已使用这些资源绘制HUD、菜单和机器面板预览。

当前可运行演示由[客户端场景](../../apps/client/src/scene.rs)和[服务端装配](../../apps/server/src/bootstrap.rs)使用基础内容夹具、动作与库存模块构建。机器示例另由Mod包装配。独立的游戏定义、模块选择与规则配置尚未在此目录建立。

基础游戏通过公开接口组合通用能力，世界与模拟内核不根据游戏名称硬编码玩法。新增内容、规则或资源时，应同步检查客户端和服务端的内容兼容性。运行方式见[项目README](../../README.md)。
