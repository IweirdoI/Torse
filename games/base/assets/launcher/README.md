# Startup artwork

`forest.png` is the current menu background, generated with the built-in ImageGen
tool on 2026-10-25. The 1672x941 source is embedded by the client and cropped to
cover the viewport without distortion. It is a photographic forest illustration,
separate from the live terrain renderer. The application draws all controls,
hover animations, tooltips and loading transitions.

Final forest generation prompt:

```text
Use case: photorealistic-natural. Asset type: full-screen background photograph for Torse's desktop game start menu. Primary request: a lush, verdant, real-looking forest, not a voxel or block landscape. Wide 16:9 landscape. Eye-level view into a mature temperate forest, tall natural tree trunks, layers of vibrant but realistic green ferns, moss, leafy canopy, a quiet narrow woodland trail receding toward the middle distance. Soft morning sun shafts filtering through leaves, subtle atmospheric haze, detailed organic bark, dappled light, natural green and warm neutral palette, immersive calm, photographic realism. Compose a coherent forest view with a gently lit middle distance and darker foliage around the edges; keep the lower central foreground relatively uncluttered and evenly shaded to support a small bottom-centered icon dock. No people, no animals, no buildings, no signs, no text, no logos, no interface, no watermark. Background artwork only, no UI mockup.
```
