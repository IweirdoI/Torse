# 基础游戏地形贴图

本目录保存基础游戏的地形图集。图集由[make-textures.py](make-textures.py)用固定种子程序生成，全部像素为自绘，不包含第三方美术资源；重新运行脚本即可得到同一份结果。

## 图集布局

图集为120x24的RGBA图像。五张16x16的图块按24像素间距排布，四周留8像素空白，图块之间也留出空白，供mipmap生成时向外扩张。

| 区域 | 起始坐标 | 内容 |
|---|---|---|
| 石头 | (4, 4) | 灰色噪点表面，带少量暗斑 |
| 玻璃 | (28, 4) | 浅蓝半透明边框与高光，用于`blend`模式 |
| 植物 | (52, 4) | 透明背景上的绿色叶片，用于`mask`模式 |
| 缺失 | (76, 4) | 品红与黑色的棋盘格，没有图集条目的材质显示它 |
| 白色 | (100, 4) | 纯白方块，供实体色块等需要着色的调试表面采样 |

空白区在两个方向上都至少留一个像素。贴图包的校验要求每个矩形之间以及矩形与图集边界之间至少隔一个像素；图块紧贴时启动失败并指出发生冲突的材质。

## 与内容的绑定

客户端在[texture.rs](../../../../apps/client/src/texture.rs)的`base_pack`中把内容材质键映射到图集矩形：

| 材质键 | 图集矩形 |
|---|---|
| `base:material/stone` | (4, 4, 16, 16) |
| `base:material/glass_slab` | (28, 4, 16, 16) |
| `base:material/plant` | (52, 4, 16, 16) |

混合模式来自内容定义`RenderProfile::alpha_mode`，不在图集里声明：石头不透明，玻璃半透明，植物二值透明。没有图集条目的材质显示缺失图块，补图前能直接看出漏配。

## 采样与mipmap

客户端生成三级mipmap。生成前把每张图块内的透明像素填成最近的实色像素，再把图块的边缘向外扩张一个像素，最后逐级减半。这样低层采样不会把相邻图块或透明黑边混进来。

放大使用最近邻保持像素风，缩小使用线性过滤并在层级之间线性混合。二值透明在片元阶段按alpha阈值丢弃，因此远处的薄叶片会随层级变细，属于当前已知限制，后续用alpha覆盖率修正。

## 再生

修改脚本来调整图案；运行前需要Python与Pillow：

```sh
python games/base/assets/textures/make-textures.py
```

图集在编译期嵌入客户端，重新生成后需要重新编译。新增材质时同时更新`base_pack`的条目与本节表格。
