# 跨模块验证

本目录供项目各部分的跨模块验证共用，并保留跨模块场景与数据说明。当前可执行测试位于各crate和`crates/codec/tests`，已覆盖M0类型、内容编译、模块解析、动作注册和codec场景；跨模块权威世界测试仍待A/B载荷契约落地。

| 目录 | 用途 |
|---|---|
| [scenarios](scenarios/README.md) | A与B联调、恢复和两客户端一致性场景 |
| [fixtures](fixtures/README.md) | 可复现的快照、提交记录与损坏数据样例 |

目前场景与数据说明列出B部分的初始计划，其他负责人可按主题补充各自场景。此聊天后续只实现B部分及其接入验证。
